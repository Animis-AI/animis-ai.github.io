The same pipeline, as an API

Everything on this page is scriptable. Jobs are asynchronous; results arrive by polling or webhook. Formats: COCO, YOLO, JSONL, WebDataset shards.

ENDPOINTWHAT IT DOES
POST /v1/videosUpload a video (multipart or signed-URL pull). Returns video_id.
POST /v1/augmentCreate an augmentation job: ops list (photometric, flip, crop, speed, noise), number of variants, seed. Returns job_id.
POST /v1/annotateCreate an annotation job: tasks among hand_pose, bbox, mask, caption. Returns job_id.
GET /v1/jobs/{id}Job status and, when done, download URLs for variants / annotation files.
POST /v1/webhooksRegister a callback for job.completed / job.failed.
# augment + annotate one clip, 8 variants curl -X POST https://api.animis.ai/v1/videos \ -H "Authorization: Bearer $ANYEGO_KEY" -F "file=@kitchen_pick.mp4" # → {"video_id":"vid_8f2k"} curl -X POST https://api.animis.ai/v1/augment \ -H "Authorization: Bearer $ANYEGO_KEY" -H "content-type: application/json" \ -d '{"video_id":"vid_8f2k","variants":8,"seed":7, "ops":["photometric","hflip","crop_zoom","speed","sensor_noise"]}' curl -X POST https://api.animis.ai/v1/annotate \ -H "Authorization: Bearer $ANYEGO_KEY" -H "content-type: application/json" \ -d '{"video_id":"vid_8f2k","tasks":["hand_pose","bbox","mask","caption"]}'
